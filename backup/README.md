# Saved versions of Aldeia Staff Desk

## v2.3.0 (live site before the test-pilot features), saved 11 Nov 2026

- `Aldeia-Staff-Desk-v2.3.0-live-site.zip`: the website files exactly as they ran (index.html, sw.js, manifest, icons). To restore, unzip and upload these files to the main folder of this repository.
- `Aldeia-Staff-Desk-v2.3.0-source.zip`: the working files used to build that version (app code, styles, build script, Firestore rules).

The same version also stays in the GitHub history as commit `aab6789`.

Staff, children, plans and messages are **not** in these files. They live in Firebase. Export them from the app under Setup → Backup and keep that file safe as well.
